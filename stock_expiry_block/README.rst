Block Expired Lots on Receipt
==============================

**Block receipt validation when lots/serial numbers are expired.**

This module prevents validating vendor receipts (incoming shipments)
if any lot or serial number has an expired date.

Features
--------
* Checks Expiration Date
* Checks Best Before Date  
* Checks Removal Date
* Shows clear error message when validation is blocked

Usage
-----
Install the module and it will automatically block any receipt
validation where lots/serials have expired dates.
